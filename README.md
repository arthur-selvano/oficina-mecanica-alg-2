2. INFORMAÇÕES NECESSÁRIAS PARA COMPILAÇÃO e EXECUÇÃO
------------------------------------------------------------------------

Por ter multiplas bibliotecas de funções, torna-se necessário que o compilador seja ajustado para executar todos os arquivos ".c" das bibliotecas, sendo eles: funcoes_oficina.c, CRUD_veiculo.c e CRUD_mecanico.c.

Para isso, abra a pasta do projeto e execute o seguinte comando em terminal:
"gcc main.c funcoes_oficina.c CRUD_mecanico.c CRUD_veiculo.c -o main.exe"
